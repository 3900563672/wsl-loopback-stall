# 08 系统恢复操作步骤（WSL 退化态 → 健康态）

> 场景：2026-08-18 深夜，WSL 处于"新端口注册失效"退化态（#41286 家族严重形态，实验压力导致）。
> 表现：guest 内新端口 1-12ms 注册成功，但 Windows 侧 30s+ 不可达；netstat 无 LISTEN、有 curl TIME_WAIT（虚拟握手黑洞）。
> 唯一已知恢复方式：`wsl --shutdown`（2026-08-18 白天验证过 R1 恢复成功）。

## 前置确认（恢复前必读）

- ⚠️ `wsl --shutdown` 会关闭**所有** WSL 发行版（含 Ubuntu）和 Docker Desktop 依赖的 WSL 引擎
- ⚠️ Docker Desktop 内置 Kubernetes 的节点容器（desktop-control-plane、desktop-worker2~9 等）**不会自动恢复**，需手动重新启用
- ⚠️ 不要动代理配置（系统代理 127.0.0.1:7890）
- ✅ 研究材料已归档到 `C:\Users\hh\OneDrive\research\`，WSL 重启无丢失风险
- ✅ `/tmp` 下的源码 clone（wsl-master/openvmm sparse）已归档到 research/，无需保留

## 恢复步骤

### 第 1 步：保存现场（可选，5 分钟）

如果还想保留退化态现场（日志已收集，一般不需要）：

```powershell
# 现场已在日志包中：logs\WslLogs-2026-08-18_22-27-23.tar.gz
# 如需补充 netstat 快照：
netstat -ano > C:\Users\hh\OneDrive\logs\degraded-netstat.txt
```

### 第 2 步：执行 wsl --shutdown

```powershell
wsl --shutdown
```

- 无输出即成功；可用 `wsl -l -v` 确认所有发行版为 Stopped
- 若 Docker Desktop 正在运行，建议先退出 Docker Desktop（托盘图标右键 → Quit），避免它自动拉起 WSL

### 第 3 步：重新启动 WSL 并验证健康态

```powershell
wsl -d Ubuntu
```

在 WSL 内：

```bash
cd /mnt/c/Users/hh/OneDrive/research
./wsl-localhost-probe -rounds 3 -timeout 10s -wincheck
```

**健康标准**：
- round 1 first-success ≈ 50-100ms（健康态注册延迟）
- win=ok:XXms（Windows 侧可达）
- 3 轮全部正常

补充对照（固定端口）：

```bash
./wsl-localhost-probe -rounds 1 -timeout 10s -wincheck -fixed 28999
```

健康标准：first-success 快、win=ok。

### 第 4 步：恢复 Docker Desktop 与 Kubernetes

1. 启动 Docker Desktop（等托盘图标变绿，约 1-3 分钟）
2. 验证 Docker：`docker ps` 应显示容器（hello-k8s-ai-test-e2e-control-plane 等）
3. **手动重新启用内置 Kubernetes**：Docker Desktop → Settings → Kubernetes → 勾选 Enable Kubernetes → Apply & Restart
   - 等待节点就绪：`kubectl get nodes`（desktop-control-plane 等 11 个节点）
   - 若未恢复：Settings → Kubernetes → Reset Kubernetes Cluster（会清空集群内资源，慎用；只在内置 K8s 没起来时用）

### 第 5 步：最终验证

- [ ] 探针 3 轮全过 + win=ok（第 3 步）
- [ ] `docker ps` 容器正常
- [ ] `kubectl get nodes` 集群 Ready
- [ ] 项目一键启动/页面可访问（用户自行确认）

## 恢复后注意事项

- 若恢复后新端口**仍然**不可达（概率低）：重跑日志收集（tools/collect-wsl-logs.ps1 提权 + UAC）或考虑整机重启（用户在场时）
- 恢复后如需补 200 轮直方图（独立 issue 用）：

```bash
cd /mnt/c/Users/hh/OneDrive/research
./wsl-localhost-probe -rounds 200 -timeout 30s -wincheck > hist200.log 2>&1
```

- 探针/日志收集工具都在 research/ 和 logs/tools/，不依赖 /tmp
